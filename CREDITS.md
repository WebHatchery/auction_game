# Credits and attribution

## Game

Auction House Tycoon is made by WebHatchery. The title artwork, catalog thumbnail, property illustrations, and interface presentation are original project assets.

## Audio

The shipped audio feedback is generated at runtime with the procedural synthesizer from `macroquad-toolkit`; the project does not ship third-party music or sound recordings.

## Software

- [Macroquad](https://github.com/not-fl3/macroquad) provides the game runtime and rendering layer.
- `macroquad-toolkit` provides shared persistence, UI, settings, audio, and font helpers.
- The interface uses the Rajdhani typeface from the toolkit asset bundle under the SIL Open Font License 1.1. See the toolkit's `assets/fonts/OFL-Rajdhani.txt` for the license text.
