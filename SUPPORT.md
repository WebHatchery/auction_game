# Support

Report bugs and platform-specific issues in the [GitHub issue tracker](https://github.com/WebHatchery/auction_game/issues).

Please include the game version, browser or Windows version, window size, the action that exposed the issue, and whether it can be reproduced from a new campaign. For save/load problems, include the screen where the problem appeared and whether the save was created in the browser or Windows build; do not attach private files unless requested.

The game is provided under the MIT License. Support is best-effort and does not include recovery of corrupted local saves.
